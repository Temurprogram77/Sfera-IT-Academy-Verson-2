# 🎓 Sfera IT Academy — CRM Platform (Version 2)

A dedicated, full-featured Educational CRM web application tailored specifically for **Sfera IT Academy** to streamline academic and administrative workflows.

---

## 📌 Problem & Solution

* **The Problem:** Traditional management methods relying on manual Excel sheets, paper logs, and scattered notes are inefficient, error-prone, and time-consuming.
* **The Solution:** This centralized CRM system replaces spreadsheets with an automated, intuitive web interface—providing real-time tracking, structured data organization, and transparent reporting for the entire academy.

---

## ✨ Key Features

- **👨‍🎓 Student & Teacher Management:** Centralized database for managing student profiles, teacher assignments, and contact records.
- **🏫 Classroom & Group Scheduling:** Automated allocation of groups, learning spaces, and timetables.
- **📊 Automated Grading System:** Easy-to-use grading interface to evaluate, track, and monitor student academic performance over time.
- **✅ Digital Attendance Tracking:** Fast and reliable attendance logging with instant record keeping.
- **⚡ Modern & Responsive UI:** Clean, modern dashboard interface designed for fast daily operations.

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **State Management & Data Fetching:** TanStack Query (React Query)
- **Routing:** React Router DOM
